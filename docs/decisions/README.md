# Decision records

One short file per decision: `NNNN-kebab-title.md`. Never edit an accepted record to change
its decision; write a new one that supersedes it and mark the old one `Superseded by NNNN`.

Template:

```
# NNNN. Title
Status: Proposed | Accepted | Superseded by NNNN
Date: YYYY-MM-DD

Context: why a decision is needed (2-4 sentences).
Decision: what we chose.
Consequences: what this makes easy, what it makes hard, what we'd revisit.
```
